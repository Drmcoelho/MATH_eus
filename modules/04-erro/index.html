O erro também tem forma

O erro encolhe. Mas encolhe com que forma?

Três laboratórios deixaram números de erro para trás. Agora o erro deixa de ser resto e vira o objeto: vamos dobrar os lados repetidas vezes e medir o que acontece.

Entenda

A forma se chama quadrática

A tabela mostrou duas estabilizações: cada dobra divide o erro por cerca de 4, e o produto n² × erro para num valor fixo. As duas dizem a mesma coisa:

erro ≈ C / n²
C
a constante da série — o valor onde n² × erro estabiliza
n
número de lados
≈
aproximação que melhora conforme n cresce

O que ela diz: dobrar n multiplica n² por 4 — por isso o erro cai para um quarto. Dez vezes mais lados, cem vezes menos erro.

Honestidade: uma tabela que estabiliza é evidência experimental, não demonstração. A origem exata das constantes está na Oficina.

No gráfico: com as duas escalas logarítmicas, "quadrática" vira uma linha reta — a cada dobra de n, o erro desce o mesmo tanto. A forma do erro é literalmente visível.

Agora use a forma

Com n = 96, o erro do contorno de dentro é ≈ 0,00112. Para um erro cem vezes menor, quantos lados?

Sem calcular seno nenhum: a forma quadrática responde sozinha.

Entenda as constantes

Quatro séries, apenas duas constantes

Troque a série no laboratório e olhe onde n² × erro estabiliza. As quatro séries se acomodam em só dois valores: ≈ 10,335 para contorno de dentro e área de fora; ≈ 20,671 — exatamente o dobro — para contorno de fora e área de dentro.

Não é coincidência nova: são os mesmos parentescos dos Laboratórios 02 e 03 — a razão dos erros do cerco descendo para 2 e o empate do circunscrito — agora vistos pelo lado das constantes.

Agora use a fórmula

Sem calcular tangente nenhuma, estime o erro da área de fora em n = 50.

Use erro ≈ C / n² com a constante certa da série.

Primeira pista

Área de fora compartilha constante com qual outra série? Olhe o parágrafo acima: só há dois valores possíveis, ≈10,335 e ≈20,671.

Pista visual

Área de fora está emparelhada com contorno de dentro: constante ≈ 10,335 = π³/3. Divida por n².

Solução comentada

10,335 / 50² = 10,335 / 2500 ≈ 0,00413. Troque a série para "área de fora" no laboratório e dobre até n = 50 (ou perto disso): o valor real bate em ≈ 0,00414 — a diferença é só porque a fórmula é assintótica, cada vez mais exata quanto maior o n. Usar a constante errada (20,671) dobraria a estimativa; usar C/n em vez de C/n² erraria por um fator de 50.

Segredo de mestre: agora que o erro tem forma, ele virou promessa: escolha qualquer tolerância — 0,001? 0,000001? — e a forma quadrática entrega um n que garante erro menor. Transformar essa promessa em garantia formal é a pergunta que abre o Laboratório 05.

Oficina — de onde vêm as constantes e o nome oficial

As folgas cúbicas. Para θ = π/n pequeno, sen(θ) fica abaixo de θ por aproximadamente θ³/6, e tg(θ) fica acima por aproximadamente θ³/3. O erro do contorno de dentro é 2n(θ − sen θ) ≈ 2n · θ³/6 = π³/(3n²); o de fora, 2n(tg θ − θ) ≈ 2π³/(3n²). As áreas seguem o mesmo caminho com o dobro ou a metade do peso — daí as duas constantes π³/3 ≈ 10,335 e 2π³/3 ≈ 20,671.

O nome oficial. Dizer que o erro "tem forma quadrática" é dizer que n² × erro tende a uma constante. A notação usual é erro = O(1/n²), lida como "da ordem de um sobre n ao quadrado". O símbolo comprime exatamente a experiência da tabela — e só por isso ele entra agora.

Estabilizar não é provar. A tabela dá evidência para finitos valores de n. A garantia para todo n vem das desigualdades por trás das folgas, que o verificador do módulo testa numericamente até n = 3072 e uma demonstração completa fecharia com desigualdades de série de Taylor.
