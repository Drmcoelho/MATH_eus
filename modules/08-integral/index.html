Leia a figura: cada retângulo do perfil representa um disco de espessura Δx. A soma é um volume, não uma área plana.

Entenda

Integral é uma soma que aceita ser refinada

VN = Σ π(R² − xᵢ²) Δx

O ponto médio de cada fatia escolhe um disco representativo. Para esta função quadrática, o erro não é apenas aproximadamente conhecido: ele é exatamente

VN − ⁴⁄₃πR³ = 2πR³ / (3N²)

Por isso dobrar N divide o erro por 4. Quando N cresce sem limite, a soma converge para:

∫−RR π(R² − x²) dx = ⁴⁄₃πR³

Transfira

Para R = 1, qual é o menor N que deixa o erro abaixo de 0,001?

Oficina — a conta fechada do erro

Com N fatias iguais, Δx = 2R/N e os pontos médios são simétricos. Somar os quadrados desses pontos reduz a soma a uma fórmula polinomial. O resultado é VN = 4πR³/3 + 2πR³/(3N²).

O termo extra é positivo porque a função π(R² − x²) é côncava: o retângulo do ponto médio fica ligeiramente acima da curva em cada fatia.

Para R = 1, exigir 2π/(3N²) < 0,001 dá N > √(2000π/3) ≈ 45,76. Portanto o menor inteiro é 46.
