Entenda

Essa promessa tem nome: limite

Você viu o contrato funcionar: qualquer tolerância, por menor que fosse, ganhou um N — e depois de N o cerco nunca mais saiu da faixa. Em linguagem corrida:

todo ε ganha um N — e, de N em diante, o cerco fica a menos de ε do círculo, para sempre
ε
a tolerância que você escolhe, sempre por atacar
N

para sempre
todo n ≥ N, sem exceção e sem recaída

Isso é exatamente o que significa dizer que os cercos têm limite 2π. Limite não é "chegar lá": é vencer todas as tolerâncias, uma a uma, com garantia.

Honestidade: a máquina testa finitos n. A promessa vale para todos porque a largura do cerco só faz descer — a monotonia está verificada numericamente no módulo e demonstrada na Oficina.

Entenda até o fim

O limite é o único sobrevivente do cerco

Cada cerco é um intervalo que contém 2π. Conforme n cresce, os intervalos encaixam uns nos outros e a largura vence toda tolerância. Pergunta decisiva: que números sobrevivem dentro de todos os cercos? Só um. Qualquer outro número fica a uma distância fixa de 2π — e algum cerco, cedo ou tarde, fica mais estreito que essa distância e o expulsa.

Por isso o limite não é um "quase": é o único número que o cerco infinito não consegue expulsar. Foi assim que, sem medir círculo nenhum, encurralamos 2π.

Segredo de mestre: a previsão N ≈ √(31/ε) acertou a resposta exata da máquina em todas as tolerâncias do painel. Conhecer a forma do erro transforma busca em cálculo — guarde isso: vai voltar quando formos fatiar áreas e volumes.

Porta futura: com o limite no bolso, o plano ficou pequeno. No Laboratório 06, ainda em construção, o polígono ganha altura e vira prisma — e o cerco inteiro vai junto.

Oficina — a frase formal, a monotonia e a estimativa de N

A frase oficial. "A sequência dos cercos tem limite 2π" escreve-se: para todo ε > 0 existe N tal que, para todo n ≥ N, |cerco(n) − 2π| < ε. É letra por letra o contrato do laboratório: ε é a tolerância escolhida, N é a resposta da máquina, e o "para todo n ≥ N" é a cláusula sem recaída. A notação só comprime a experiência que você acabou de ter.

Por que não há recaída. O contorno de dentro, 2nR·sen(π/n), só cresce com n; o de fora, 2nR·tg(π/n), só decresce. Logo a largura do cerco, a diferença dos dois, é estritamente decrescente: uma vez abaixo de ε, abaixo para sempre. O verificador do módulo confere as três monotonias até n = 5000.

De onde vem a previsão. A largura do cerco é a soma dos dois erros de contorno, e o Lab 04 deu as constantes deles: π³/3 + 2π³/3 = π³ ≈ 31,006. Logo largura ≈ π³/n², e exigir π³/n² < ε dá n > √(π³/ε) — a conta de cabeça N ≈ √(31/ε) do desafio.

Finitos testes não provam. A varredura "sem recaída até N + 3000" é evidência; a garantia para todo n é a monotonia acima, que uma demonstração completa fecha com as desigualdades de sen e tg do intervalo (0, π/3].
